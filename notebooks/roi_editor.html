ROI Editor

Purpose: draw per-location ROIs + legal flow and export a standardized JSON config.
Left click add vertex
Enter finish polygon
Backspace undo last vertex
Esc cancel current polygon
Flow mode: click start → click end (arrow)
Tip: extract one representative frame per location (e.g., data/frames/loc_01.jpg).
JSON includes: image size, ROIs (list of polygons), and flow arrow.

  },
  "flow": { "type":"arrow", "vector": {"x1":..,"y1":..,"x2":..,"y2":..} }
